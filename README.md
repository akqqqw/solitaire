# Пасьянс Клуб

Четыре классических пасьянса в одном приложении: **Косынка**, **Паук**, **Свободная ячейка** и **Пирамида**. Общий стол, статистика, достижения, ежедневные испытания и сохранение незавершённых партий.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # проверка TypeScript
npm run test       # Vitest
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр сборки
```

Node.js 20+.

## Что умеет

- **Косынка** — 7 столбцов, режимы по одной и по три карты, автосборка, отмена, подсказки, таймер, счёт.
- **Паук** — 104 карты, 10 столбцов, сложность на 1/2/4 масти, переносы одной масти, автоматическое снятие король—туз, раздача из резерва с запретом при пустых столбцах.
- **Свободная ячейка** — 52 открытые карты, 8 столбцов, 4 ячейки и 4 базы, лимит переноса по формуле FreeCell, расклады по номеру.
- **Пирамида** — 28 карт в семи рядах, пары на 13, король отдельно, колода/сброс и неограниченные перевороты, победа при разборе пирамиды.

Общее:

- меню с процентом побед и лучшим временем по каждому режиму;
- статистика по режимам и карьере, 29 достижений, монеты;
- детерминированные ежедневные задания и календарь наград за вход;
- сохранение партий в IndexedDB с резервной копией в localStorage;
- адаптивная вёрстка, портретная ориентация, SVG-карты и четыре рубашки;
- Yandex Games SDK как отдельный сервис: облачные сохранения, реклама, лидерборды. Без площадки игра полностью работает офлайн.

## Архитектура

```
src/
  core/
    cards/        колода, карты, правила, хеширование/перемешивание
    games/        четыре независимых модуля правил + общий интерфейс
      klondike/ spider/ freecell/ pyramid/
    session/      GameSession: ходы, отмена, таймер, сериализация
    statistics/   статистика режимов и карьеры
    achievements/ каталог достижений и разблокировка
  services/       dailyChallenges, persistence, platform (Yandex SDK), sound
  store/          Zustand-состояние приложения и профиль
  game/           Phaser-сцена, адаптеры ввода и представления (view)
  ui/             React-экраны и компоненты
  tests/          jsdom-тесты интерфейса и фикстуры
```

Правила игр не зависят от Phaser и React: модуль режима умеет создать партию, проверить ход, применить его, перечислить легальные ходы и подсказку, проверить победу/тупик и валидировать сохранение. Phaser отвечает только за отрисовку и ввод, Zustand — за состояние экранов и профиль.

## Сохранения

Профиль версионирован (`SCHEMA_VERSION = 1`), записывается в IndexedDB и localStorage с резервной копией. При загрузке данные проходят санитизацию: невалидные поля и повреждённые партии отбрасываются, а не ломают приложение. Каждая незавершённая партия хранится отдельно и восстанавливается вместе с историей отмены и таймером.

## Яндекс Игры

- `index.html` асинхронно подключает официальный SDK; при недоступности площадки приложение через короткий таймаут переходит в офлайн-режим.
- `src/services/platform.ts` — единственная точка интеграции: `LoadingAPI.ready()`, межстраничная и rewarded-реклама с паузой таймера, облачные сохранения с разрешением конфликтов по `updatedAt`, лидерборды.
- Идентификаторы лидербордов: `klondike_best_time`, `spider_best_time`, `freecell_best_time`, `pyramid_best_time`, `total_wins`.
- Для публикации достаточно загрузить содержимое `dist/`; игра не требует серверной части.

Покрыты правила всех четырёх режимов, адаптеры ввода, раскладки view на четырёх размерах экрана, сессия и отмена, статистика, достижения, ежедневные задания, сохранения и офлайн-режим SDK. Дополнительно есть детерминированный фаззинг легальных партий и кликов адаптеров.
